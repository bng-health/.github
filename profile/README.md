## Quem somos

Somos o hub de tecnologia do grupo **BNG (Boas Novas Gestão)**. Construímos software para
**operações de saúde** — de escalas médicas a telemedicina, prescrição digital e gestão de unidades —
com o objetivo de tornar o cuidado mais organizado, eficiente e humano.

Nossa engenharia trabalha com plataformas web, aplicativos móveis e serviços de backend em produção,
atendendo gestores, equipes de operação e profissionais de saúde no dia a dia.

---

## 🚀 Produto principal — Minha Escala

Plataforma completa para **gestão de escalas médicas** em unidades de saúde. Cobre todo o ciclo:
da criação da escala ao pagamento do plantão.

| Frente | Descrição | Stack |
| ------ | --------- | ----- |
| 🖥️ **Web** | Dashboard para gestores: escalas, médicos, unidades, políticas, aprovações e relatórios. | Vue 3 · TypeScript · Vuetify · Pinia |
| 📱 **App** | Aplicativo dos médicos: candidatura a plantões, check-in/check-out, controle de horas. | React Native · Expo · TypeScript |
| ⚙️ **API** | Backend modular com DDD, permissões granulares (ReBAC) e workers assíncronos. | NestJS · PostgreSQL · Redis · SpiceDB |

**Destaques do produto:**

- 🗓️ Criação e gestão completa de escalas de plantão
- ✅ Fluxo de aprovações com motor configurável
- 📍 Check-in/check-out com biometria facial para controle de presença
- 💰 Políticas de atendimento e pagamento
- 📊 Relatórios operacionais e financeiros com exportação
- 🔔 Notificações push (Firebase) e e-mails transacionais
- 🩺 Validação de CRM via API do CFM
- 😀 Pesquisa de satisfação (NPS)

## 🧩 Ecossistema BNG

Além do Minha Escala, desenvolvemos e operamos outras soluções para o setor de saúde:

- **Telemedicina (Tele-UPA)** — atendimento remoto para unidades de saúde
- **Prescrição digital** — prescrição médica com assinatura eletrônica (ICP-Brasil)
- **Reconhecimento facial** — microsserviço de identificação para controle de presença
- **Serviços financeiros** — soluções de antecipação para profissionais de saúde
